# Тесты обработчиков продуктов

В репозитории есть две версии тестов обработчиков продуктов:

- `tests-manual` использует ручной мок `ProductsMock` из `product_mock.go`.
- `tests-mockery` использует мок, сгенерированный mockery, из `internal/handlers/product/mocks/Products.go`.

Необходимо клонировать репозиторий и перейди в его каталог:

```sh
git clone https://github.com/Kai-dev99/Test-Pet-Shop.git
cd Test-Pet-Shop
```


## 🛠 Как запустить

1. Перейти в каталог проекта, клонированного по инструкции выше.

2. Настроить окружение: скопировать `.env.example` в `.env` и поправить логин, пароль и имя базы.
`cp .env.example .env`

3. Поднять PostgreSQL и применить миграции:
`docker compose up -d postgres`
`task migrate`

4. Запустить сервер (конфиг `config/local.yaml`, другой выбирается через `APP_ENV`):
`go run ./cmd/app`

5. После этого API будет доступно по адресу:
`http://localhost:8080`, проверка — `GET /health`.

Всё сразу в контейнерах: `docker compose up -d --build` (приложение берёт `config/dev.yaml`).


Запусти тесты сначала с ручным моком, затем со сгенерированным. Для этих тестов достаточно Go.

```sh
git switch tests-manual
go test ./...
git switch tests-mockery
go test ./...
```


В ветке `tests-mockery` после изменения интерфейса `Products` перегенерируй мок:

```sh
go generate ./...
```

# 🐾 Go Pet Shop

**Go Pet Shop** — это учебный проект интернет-магазина товаров для питомцев, написанный на Go с использованием PostgreSQL.  
Он создан для отработки навыков работы с SQL-запросами, транзакциями и построения REST API.

---

## 🚀 Основная идея

Проект моделирует классический онлайн-магазин с товарами, пользователями, заказами и оплатами.  
Цель — показать полный цикл разработки от работы с базой данных и CRUD-операций до реализации транзакций и аналитики.

---

## 🔑 Возможности проекта

- 📦 Управление товарами (добавление, обновление, удаление, просмотр списка и конкретного товара).  
- 👤 Работа с пользователями (регистрация, получение списка и конкретного пользователя).  
- 🛒 Создание заказов и добавление позиций.  
- 💳 Оформление заказов в транзакции (уменьшение остатков, создание заказа, позиций и транзакции оплаты).  
- 📊 Просмотр истории заказов и аналитики (популярные товары, детали заказов и транзакций).  
- ✅ Health-check для проверки состояния сервера.

---

## ⚙️ Технологии

- **Go** — основной язык разработки.  
- **PostgreSQL** — база данных.  
- **golang-migrate** — управление миграциями БД.  
- **golangci-lint** — статический анализ кода.  
- **Taskfile** — автоматизация запуска миграций, линтера и других команд.

---

## 📂 Структура проекта

```
go-pet-shop/
├── cmd/ # Точки входа (app — сервер, migrator — миграции)
├── config/ # Конфигурация (yaml/json)
├── internal/ # Хендлеры, работа с БД, конфиг, логгер
│   └── models/ # Доменные модели и DTO
├── migrations/ # SQL-файлы миграций
├── .env # Переменные окружения (не хранится в git, шаблон — .env.example)
├── Taskfile.yaml # Скрипты для работы с проектом
├── go.mod # Модуль Go
└── README.md # Документация
```
